# WhatsOnChain

[WhatsOnChain](https://whatsonchain.com) is a blockchain explorer for the BSV network. It lets you look up and understand publicly recorded blockchain activity through a website, without running your own blockchain node.

You can use WhatsOnChain to:

- Look up a transaction to check whether it has been confirmed in a block.
- View an address's balance and transaction history.
- Browse blocks and see the transactions they contain.
- Explore data recorded on the blockchain and view network statistics.

For developers, WhatsOnChain also provides a REST API so applications can retrieve blockchain data and broadcast transactions programmatically. Wallets, payment services and other applications can use it to check balances, track transactions and find unspent transaction outputs (UTXOs), the outputs available to spend. The explorer and API support BSV mainnet and testnet.

This repository is the public community hub and issue tracker for WhatsOnChain, under the BSV Association.
